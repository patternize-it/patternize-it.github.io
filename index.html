Built for the whole session, not just the file.

Most tools stop at rendering a recording. Patternize is built around the questions a clinician or researcher actually asks next.

Multichannel EEG viewer

Load an EDF recording and get every channel scaled and time-aligned correctly from the start — no overlapping traces, no guessing at units, no manual rescaling before you can actually look at the data.

Camera-based motor tests

Finger-to-nose, finger tapping, and pronation/supination tests run through the webcam, tracked and scored automatically using hand and pose landmarks — no external sensors required.

Per-patient history

Every recording and every test result is filed against the patient it belongs to, so a session adds to a timeline instead of replacing the last one.

One diagnostic panel

EEG findings and motor scores sit next to each other in a single view, instead of living in separate tools that have to be cross-referenced by hand.

How a session runs

Four steps, from raw recording to a reviewed diagnostic panel.

01

Load the recording

Drop in an EDF file. Patternize reads every channel, its sampling rate, and the total recording length automatically.

02

Read the trace

Each channel renders on a clinically sensible scale, aligned to its own timebase, so nothing overlaps or misleads.

03

Run the movement tests

Finger-to-nose, tapping, and rotation tests are scored live from the webcam feed, right alongside the EEG.

04

Review the panel

EEG and motor results land together in one diagnostic panel, saved to the patient's record for next time.
