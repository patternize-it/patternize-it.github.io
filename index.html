The problem

An exam produces an impression. Rarely a number.

Finger-to-nose, a scan through an EEG, a quick check of reaction speed: each gives a real reading of brain function in the moment. Almost none of it is recorded in a form you can compare with the last visit, so small changes get missed because nothing was measured the same way twice.

What it measures

Four kinds of signal, one patient record.

Each module runs today inside the same app and saves into the same record. Every measure has a defined unit, so a number from March means the same thing as one from June.

Movement

webcam or video file

Hand and body landmarks tracked from an ordinary webcam, turned into kinematics for the motor exam.

  • Finger-to-nose: path, endpoint error, terminal tremor, smoothness
  • Finger tapping: speed, amplitude, decrement, rhythm, hesitations
  • Rapid alternating: frequency, rotation range, regularity

EEG

EDF · BDF · BrainVision · FIF · more

A full reading workspace with standard montages, calibrated sensitivity and filters, plus the quantitative view alongside.

  • Spike and artifact screening, reviewed by you
  • Scalp maps per frequency band, coherence
  • Hemispheric symmetry and dominant rhythm

Voice

microphone or WAV file

A sustained vowel, recorded in the visit, analysed for phonation stability, a marker for motor speech.

  • Pitch and pitch variability
  • Jitter, shimmer, harmonics-to-noise
  • Maximum phonation time

Cognition

screen + keyboard

Timed tasks run by the app itself, so every patient gets the same instructions and the same timing.

  • Reaction time: mean, median, variability
  • Misses and anticipations
  • Slowing across the task

Inside the app

The EEG workspace, as your team will see it.

Read the recording the way you normally do, with the quantitative view open next to the traces.

  • Longitudinal, transverse, average and Laplacian montages at calibrated µV/mm
  • Scalp topography for the visible window, per frequency band
  • Spike and artifact candidates on a timeline, confirmed or rejected by you
  • Symmetry and dominant rhythm saved with the visit and charted over time
The patient record

Not a score. A trajectory.

Every saved test goes into the patient's record. Each measure gets its own line over time, and each visit shows what moved since the one before. Green means improvement, red means worse, judged by that measure's own direction.

Built to grow

Every test is an entry in a catalog.

Each test and each measure is defined in one place: what it's called, its unit, which way is better, and the code that computes it. That makes the record easy to extend and easy to audit.

  • Add a measure to an existing test without touching its analysis
  • Swap in a more accurate detector, and every chart and report follows
  • Each result stores the version that produced it, so numbers are never silently mixed
  • Your site can relabel measures or add its own tests

Trust

Built to be checked, not just believed.

Grounded in existing exams

Every measure traces back to a task neurologists already use, such as finger-to-nose, finger tapping, standard EEG bands and reaction time. None of them is an invented test.

Labelled at the source

Each result records the algorithm version, its parameters and a quality check (for example, how often the hand was in view), so you can see what a number rests on.

Re-analysable

Raw landmark streams and recordings are kept with each visit. When an analysis improves, earlier visits can be re-run and compared like with like.

Your data stays with you

The app runs on your workstation. Recordings and the patient database are stored locally, with nothing sent to a cloud service.

Pseudonymous by design

Patients are filed under a code. Names are optional, stay in the local database, and never appear in folder names or exports.

Built with pilot clinics

Rolled out module by module with practicing neurologists rather than all at once, and clear that it is a research tool until validated.

FAQ

Questions clinics ask first.

Is Patternize a diagnostic device?

No. It measures and charts; it does not diagnose, score risk or recommend treatment. It is a research tool, not yet available for clinical use, and its measures are still being validated with pilot clinics.

What hardware do we need?

A Windows or macOS computer with an ordinary webcam and microphone. EEG is read from files your existing system already exports (EDF, BDF, BrainVision, FIF, EEGLAB, EGI, Persyst, Nicolet and more), so you need no new amplifier.

Where is patient data stored?

On the workstation, in a data folder you choose, which can be an encrypted drive. Each visit is a self-describing folder, indexed in a local database you can back up or open with standard tools.

How long does an assessment take?

The movement and voice tasks take seconds each, and a reaction-time block takes a few minutes. An EEG reading takes as long as your usual review, with the quantitative panels already computed.

Can we add our own tests or measures?

Yes. Tests and measures are defined in a catalog, so a site can relabel measures, add derived ones, or plug in a new analysis without changing the rest of the app.
